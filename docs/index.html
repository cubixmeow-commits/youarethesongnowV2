Direction

Rebuild the value, not the files

Architecture

PHP + SQLite first

Song DNA

Structured song meaning before pixels. V1 proved the 12-field blueprint; V2 should keep the idea and slim the responsibilities.

Visual Narrative Plan

Choose one readable moment. Stop asking the image model to invent the story, style, casting, and safety all at once.

Artist Visual Identity

A visual brief — not a lore bible. Dynamic Band Style in V1 was StyleMap machinery wearing lore marketing.

Portrait Integration

“Put me in the song” needs an explicit identity contract and no silent fallback drops.

Prompt Compiler

Assemble ranked artifacts into provider-facing text. Testable. Versioned. Replaceable.

Retry Strategy

Demote style and framing before identity. If identity can’t be kept, label the result honestly.
