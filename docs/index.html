WHAT WE FOUND

Arcana was already more ambitious than a simple image generator.

The legacy app had a real creative pipeline: interpret the song, derive structured visual meaning, build a cinematic prompt, generate the image, recover from failures, save the result, and manage the user's history.

01

Song DNA

Lyrics, artist and song context were analyzed into structured themes, mood, palette, camera and composition ideas before image generation began.

CORE CONCEPT
02

Dynamic Band Style

A special analysis path could build a band-specific StyleMap so the imagery felt attached to the artist instead of using a generic visual preset.

PARTIALLY EXPOSED IN V1
03

You enter the image

Users could provide one or two portrait references that were incorporated into the generated scene, one of the defining ideas behind YouAreTheSongNow.

WHAT V1 ACTUALLY CONTAINED

Eight product systems were intertwined in the old app.

Accounts

Registration, login, verification, password reset, profile and maintenance access.

Plans & Credits

Tier-gated features plus image/story credits and Stripe-backed purchasing.

Generator

Song inputs, custom instructions, styles, portraits, aspect ratios and queue submission.

AI Workers

Song analysis, prompt construction, image generation, retries and notifications.

Gallery

Search, sorting, pagination, lightbox, email and deletion of renders.

Payments

Checkout, subscriptions, credit packs and multiple legacy webhook paths.

Storage

Local media plus Backblaze B2, thumbnails, portrait references and public URLs.

Admin & System

Admin tools, maintenance mode, legal pages, feedback and transactional email.

PRESERVE THE IDEA

What looks worth carrying forward.

  • Song interpretation before image generation
  • Explicit Song DNA as a domain artifact
  • Dynamic artist/band visual identity
  • Portrait-reference creation mode
  • Durable async generation jobs
  • Personal project/gallery history
  • Progressive retry and safety fallbacks
LEAVE THE LEGACY BEHIND

What should not be copied blindly.

  • Multiple overlapping PHP worker scripts
  • Duplicate Stripe webhook implementations
  • Mutable credit columns as the accounting system
  • Hardwired Gemini model versions
  • Inconsistent plan enforcement
  • Public storage assumptions for user media
  • Legacy mobile redirects and duplicated generators
