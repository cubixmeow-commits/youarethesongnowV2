## Agent checklist (any design-related task)

1. Read `docs/design/CURSOR-HANDOFF.md`
2. Read `docs/design/DESIGN-OPERATING-SYSTEM.md` if the task changes system rules
3. Read only the foundation/component/screen docs relevant to the change
4. Prefer phone-first verification
5. Do not start the next phase without the listed gate
6. Update `CURSOR-HANDOFF.md` when the task finishes
