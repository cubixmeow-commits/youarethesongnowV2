# `/assets/design/` — design artifacts

Non-runtime design-system artifacts for YouAreTheSongNow.

| Path | Purpose |
| --- | --- |
| `tokens/` | Proposed / exported semantic token files |
| `references/` | Optional mood or reference stills (no lyrics, no secrets) |
| `audits/` | Audit evidence packs keyed by date |
| `exports/` | Future CSS/Flutter export bundles |

**Runtime product assets remain in** `public/assets/` (css, js, images, vendor, data).

**Round review screenshots remain in** `design/review/`.

Do not commit private portraits, raw lyrics, or credentials here.
